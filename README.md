# FCTX Japan Utopia Finder (v7)

都道府県別の「都市利便・雇用」「食・カルチャー」「レジャー・気候」に関する多様なデータを日本地図上に可視化し、ユーザー自身の価値観に合わせた最適な移住・2拠点居住先を算出・探索できる、インタラクティブな理想郷診断ツールです。画面全体をスクロールせずにすべての情報を俯瞰できるフィットスクリーン（No-scroll）レイアウトを採用しています。

## 主な機能

- **日本地図可視化**: 各指標またはカスタム総合スコアに応じて都道府県を青（低）〜 黄（中）〜 赤（高）でグラデーション表示します。
- **25カ年時系列アニメーション**: 下部のタイムラインシークバーと再生/一時停止ボタンで、**2000年〜2024年の25年間のデータ自動再生・シーク**が可能です。
  - **地価公示アノマリー**: 2000年代のデフレ下落、2008年リーマンショックでの全国急落、2013年以降のアベノミクスによる都市部上昇といった歴史のウェーブが地図に再現されます。
  - **スタバの全国浸透史**: 2000年のごく一部の大都市圏から、徐々に地方へ進出し、2015年の鳥取県進出による全県展開達成までの出店拡大の軌跡を再現。
  - **一極集中の進行**: 25年間で地方部の人口が減少し、東京周辺や大都市圏が赤みを増していく人口移動が可視化されます。
- **最適化された総合スコア計算（移住ポテンシャル調整）**:
  - **基本生活スペックの統合 (固定比重 30%)**:
    「住居費の安さ」「生活利便性」「雇用の豊富さ」の3つのマクロ指標の偏差値平均を**「基本生活力」**として固定30%の割合で背後で自動計算に組み込みます。
    - *※住居費の安さスコアは、地価が低い都道府県ほど高スコア（反転計算）となるように最適化されています。*
  - **食・レジャー・気候個性のカスタマイズ**:
    ユーザーがスライダーで比重を自由に調整できるのは、以下の 4 指標に限定されます。これらにより、自身の価値観（カフェ充実度、グルメ充実度、観光魅力度、気候の快適さ）に基づいた「自分だけの都道府県総合ランキング（理想郷）」がリアルタイムで算出されます。
    1. **カフェ充実度**: スターバックスの実店舗数
    2. **グルメ充実度**: ラーメン店の合計店舗数規模
    3. **観光・レジャー魅力度**: 観光ブランドイメージスコア
    4. **気候の快適さ**: 年間の晴れやすさ（日照時間）
  - **移住プランプリセット**:
    「都会利便性＆仕事重視」「カルチャー＆グルメ移住」「リゾート＆スローライフ」「理想のライフバランス」の4つのプランから一クリックで理想的な重みを設定可能です。
- **カテゴリー別指標切り替え**:
  指標を「都市利便・雇用」「食・カルチャー」「レジャー・気候」の3カテゴリに整理。
- **詳細データ＆進捗グラフ**: クリックした都道府県の「基本生活スペック」と「食・レジャー・気候個性」をグループ分けし、平均値（50）を基準線とした偏差値プログレスバーとともに一覧表示。
- **ランキングと上位グラフ**: 現在の指標に基づく全都道府県の順位リスト（検索フィルター付き）と、上位5位を示す Recharts 棒グラフを表示。
- **CSVアップロード (モーダルインポート)**: ヘッダーの「インポート」ボタンから、時系列および多様なデータを含むCSVをドラッグ＆ドロップまたはクリックで読み込み、その場で偏差値・総合スコアを再計算して反映できます。
- **フィットスクリーン (No-scroll) UI**: 画面全体の高さを `100vh`（ビューポートの高さ）に固定し、ブラウザ全体のスクロールなしで地図、ランキング、詳細、グラフを美しく一元管理できます。

## 可視化する7つの指標

### 1. 都市利便・雇用 (Basic - 基本生活スペックとして統合計算)
- **住居費の安さ** (`landPrice` / 円/㎡): 土地価格の安さ。地価が低いほど移住しやすいため高スコアになります。
- **生活利便性** (`population` / 人): 都市規模・人口。利便性の目安です。
- **雇用の豊富さ** (`listedCompanies` / 社): 上場企業の本社数。求人チャンスの豊富さを表します。

### 2. 食・カルチャー (Lifestyle - ユーザーウェイト調整対象)
- **カフェ充実度** (`starbucksCount` / 店舗): スターバックスの実店舗数。サードプレイスの多さを表します。
- **グルメ充実度** (`ramenCount` / 店舗): ラーメンの実店舗数。外食・ラーメン文化の熱量を表します。

### 3. レジャー・気候 (Environment - ユーザーウェイト調整対象)
- **観光・レジャー魅力度** (`attractiveness` / 点): 都道府県魅力度ブランドスコア。
- **気候の快適さ** (`sunshineHours` / 時間): 年間日照時間。晴天率が高く心地よく暮らせる度合いを表します。
