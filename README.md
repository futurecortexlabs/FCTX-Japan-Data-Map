# FCTX Japan Data Map (v6)

都道府県別の「都市力」「ライフスタイル」「気候環境」に関する多様なデータを日本地図上に色分け表示し、過去25年間（2000年〜2024年）の歴史的推移を時系列アニメーションで確認できる、インタラクティブなデータ可視化ダッシュボードです。画面全体をスクロールせずにすべての情報を俯瞰できるフィットスクリーン（No-scroll）レイアウトを採用しています。

## 主な機能

- **日本地図可視化**: 各指標またはカスタム総合スコアに応じて都道府県を青（低）〜 黄（中）〜 赤（高）でグラデーション表示します。
- **25カ年時系列アニメーション**: 下部のタイムラインシークバーと再生/一時停止ボタンで、**2000年〜2024年の25年間のデータ自動再生・シーク**が可能です。
  - **地価公示アノマリー**: 2000年代のデフレ下落、2008年リーマンショックでの全国急落、2013年以降のアベノミクスによる都市部上昇といった歴史のウェーブが地図に再現されます。
  - **スタバの全国浸透史**: 2000年のごく一部の大都市圏から、徐々に地方へ進出し、2015年の鳥取県進出による全県展開達成までの出店拡大の軌跡を再現。
  - **一極集中の進行**: 25年間で地方部の人口が減少し、東京周辺や大都市圏が赤みを増していく人口移動が可視化されます。
- **最適化された総合スコア計算（重みカスタマイズ）**:
  - **都市基礎スペックの統合 (固定比重 30%)**:
    「平均地価」「人口」「上場企業数」の3つのマクロ指標の偏差値平均を**「基礎都市力」**として固定30%の割合で背後で自動計算に組み込みます。ユーザーがこれらを個別にスライダーで動かす必要がなくなりました。
  - **ライフスタイル・環境個性のカスタマイズ**:
    ユーザーがスライダーで比重を自由に調整できるのは、以下の 4 指標に限定されます。これらにより、自身の価値観（カフェ派、ラーメン派、気候重視、観光重視）に基づいた「自分だけの都道府県総合ランキング」がリアルタイムで算出されます。
    1. **スタバ店舗数**: カフェ・サードプレイスの集積度（実店舗数）
    2. **ラーメン店舗数**: ご当地ラーメンの店舗数規模（実店舗数）
    3. **魅力度スコア**: 観光ブランドイメージ
    4. **年間日照時間**: 気候の快適性
  - **ワンクリックプリセット**:
    「都会スペック重視（ユニーク指標ウェイト0で基礎都市力100%）」「カルチャー・食重視」「観光・環境重視」「ライフバランス」の4つのプリセットで一括適用が可能。
- **カテゴリー別指標切り替え**:
  指標を「基本都市データ」「ライフスタイル・食」「気候・観光ブランド」の3カテゴリに整理。
- **詳細データ＆進捗グラフ**: クリックした都道府県の「基礎スペック」と「ライフスタイル個性」をグループ分けし、平均値（50）を基準線とした偏差値プログレスバーとともに一覧表示。
- **ランキングと上位グラフ**: 現在の指標に基づく全都道府県の順位リスト（検索フィルター付き）と、上位5位を示す Recharts 棒グラフを表示。
- **CSVアップロード (モーダルインポート)**: ヘッダーの「インポート」ボタンから、時系列および多様なデータを含むCSVをドラッグ＆ドロップまたはクリックで読み込み、その場で偏差値・総合スコアを再計算して反映できます。
- **フィットスクリーン (No-scroll) UI**: 画面全体の高さを `100vh`（ビューポートの高さ）に固定し、ブラウザ全体のスクロールなしで地図、ランキング、詳細、グラフを美しく一元管理できます。

## 可視化する7つの指標

### 1. 基本都市データ (Basic - 都市スペックとして統合計算)
- **平均地価** (`landPrice` / 円/㎡): 都市の経済力と土地価値の変動。
- **人口** (`population` / 人): 人口規模。
- **上場企業数** (`listedCompanies` / 社): 本社所在する上場企業の集積度。

### 2. ライフスタイル・食 (Lifestyle - ユーザーウェイト調整対象)
- **スターバックス店舗数** (`starbucksCount` / 店舗): スターバックスの日本全国進出の歴史（実店舗数）。
- **ラーメン店舗数** (`ramenCount` / 店舗): ラーメン店舗の実数推移。山形、栃木、新潟等が上位。

### 3. 気候・観光ブランド (Environment - ユーザーウェイト調整対象)
- **魅力度スコア** (`attractiveness` / 点): 都道府県ブランドイメージの経年推移。
- **年間日照時間** (`sunshineHours` / 時間): 過去の猛暑年や冷夏年などの気候アノマリーの推移。
