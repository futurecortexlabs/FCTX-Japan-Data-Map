# 🗾 Utopia Finder (FCTX Japan Data Map)

「あなたにとっての理想の地（ユートピア）をデータから見つけ出す」をコンセプトにした、**遊び心100%のエンタメ系データ可視化ダッシュボード**です。

一見すると都道府県のデータを可視化するスタイリッシュで真面目なツールですが、格闘ゲーム風のVSモードや、隠しコマンドによるレトロRPGモードなど、思わず触りたくなる「エンタメ機能」が多数搭載されています。

---

## ✨ 主な機能

### 🎯 理想の地を探す（コア機能）
- **Utopia スライダー (レーダーチャート)**: 「生活費の安さ」「食・娯楽の充実」「自然・環境」「都市インフラ」の4つの重みをスライダーで調整し、あなたの価値観にマッチした都道府県をリアルタイムで再計算します。
- **インタラクティブな日本地図**: 総合スコアや個別データ（地価、スタバ数、花粉の少なさなど全12種類）に合わせて、都道府県の色がシームレスに変化します。
- **トップ5ランキングチャート**: 選択した指標に基づく全県の順位リストと、上位5県を示す美しいバーチャートを表示します。
- **時系列アニメーション**: タイムラインシークバーを使って、過去から現在までのデータの変遷（スタバの全国進出の歴史など）を自動再生できます。

### 🎮 実用＆エンタメ機能
- **🔥 FIRE シミュレーター**: 「もし東京からこの県に移住したら、何年早くアーリーリタイア（FIRE）できるか？」を資産推移グラフでシミュレーションします。
- **🗣️ AI市長コンシェルジュ**: あなたの価値観に合わせてAIが移住アドバイスを生成。「フルボイス再生」をオンにすると、Web Speech APIを使った「市長風のクセのある声」で熱っぽく語りかけてきます。
- **☁️ ウェザーエフェクト**: 地図のデータに合わせて、「魅力度」なら桜の花びら、「地価」ならお札など、画面全体にユニークなパーティクルが降ってきます。
- **⚔️ VS デュエルモード**: 格闘ゲームの対戦画面のようなスプリットスクリーンで、2つの都道府県のステータスを比較して戦わせることができます。
- **🎫 搭乗券（Boarding Pass）発行**: 移住先を決定すると、SNSシェアに最適な「あなた専用の美しい航空券（Boarding Pass）」が発行され、紙吹雪でお祝いされます。
- **🏆 アチーブメント（実績解除）機能**: アプリを操作して特定の条件を満たすと、トースト通知とともにバッジが解除されるゲーミフィケーション要素です。

### 🕹️ 隠し要素「レトロRPGモード」
キーボードで**コナミコマンド（上・上・下・下・左・右・左・右・B・A）**を入力すると、アプリ全体が8ビットのレトロRPG風にバグって変身します！
- フォントがドット絵（ピクセルフォント）になり、ブラウン管の走査線エフェクトがかかります。
- チップチューンのBGMが流れ出します。
- この状態で「VSデュエルモード」を開くと、「こうげき」「ぼうぎょ」コマンドで戦う**ターン制RPGバトル**が始まります。

## 💻 技術スタックとパフォーマンス

- **フロントエンド**: React, TypeScript, Vite
- **スタイリング**: TailwindCSS
- **アニメーション**: Framer Motion, canvas-confetti
- **地図描画**: React Leaflet
- **グラフ描画**: Recharts

**🚀 徹底的な最適化による爆速ロード**
機能が盛りだくさんでありながら、日本地図の巨大な地形データ（約13MBのGeoJSON）をプログラムから切り離し、初期描画後に非同期フェッチする構造を採用。
さらに `React.lazy` による遅延読み込みと `React.memo` による徹底した再描画防止により、**メインのJSバンドルサイズをわずか約150KB**に抑え、劇的な起動スピードとサクサク動作を実現しています。

## 📊 可視化できる主な指標
- **生活・インフラ**: 地価の安さ、人口、上場企業数、病院数、子育て環境スコア
- **食・カルチャー**: ラーメン屋店舗数、スターバックス店舗数、温泉地数
- **自然・環境**: 観光魅力度、年間日照時間、花粉の少なさ
